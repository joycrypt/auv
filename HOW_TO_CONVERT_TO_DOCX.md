# How to Convert HTML to DOCX

## Method 1: Using Microsoft Word (Recommended)

1. **Download the HTML file** from GitHub:
   - Go to: https://github.com/joycrypt/auv/blob/fix/ekf-optimization/EKF_Complete_Guide.html
   - Click "Raw" button
   - Save the file (Ctrl+S or Cmd+S)

2. **Open in Microsoft Word:**
   - Right-click `EKF_Complete_Guide.html`
   - Select "Open with" → "Microsoft Word"
   - Word will automatically convert the HTML

3. **Save as DOCX:**
   - File → Save As
   - Choose "Word Document (*.docx)" format
   - Save with your preferred name

## Method 2: Using Google Docs

1. **Upload to Google Drive:**
   - Go to drive.google.com
   - Click "New" → "File upload"
   - Upload `EKF_Complete_Guide.html`

2. **Open with Google Docs:**
   - Right-click the uploaded file
   - Select "Open with" → "Google Docs"
   - Google Docs will convert it

3. **Download as DOCX:**
   - File → Download → Microsoft Word (.docx)

## Method 3: Using LibreOffice (Free)

1. **Open in LibreOffice Writer:**
   - Open LibreOffice Writer
   - File → Open
   - Select `EKF_Complete_Guide.html`

2. **Save as DOCX:**
   - File → Save As
   - Format: "Microsoft Word 2007-2019 (.docx)"
   - Save

## Method 4: Online Converter

1. **Go to any online HTML to DOCX converter:**
   - cloudconvert.com/html-to-docx
   - convertio.co/html-docx
   - onlineconvertfree.com

2. **Upload the HTML file**

3. **Download the converted DOCX**

## Tips for Best Formatting

After converting to DOCX:

1. **Adjust page margins** if needed (Layout → Margins)
2. **Check page breaks** (should be at end of each section)
3. **Verify formulas** are displayed correctly
4. **Update table of contents** if Word prompts you
5. **Save a PDF version** for presentations (File → Save As → PDF)

## Troubleshooting

**If formulas look weird:**
- They use subscripts and superscripts in text format
- You can re-format using Word's Equation Editor if needed

**If colors are missing:**
- Make sure "Display background colors" is enabled in Word
- View → Print Layout

**If tables are misaligned:**
- Select table → Right-click → AutoFit → AutoFit to Window
